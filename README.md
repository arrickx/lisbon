## ✨ 核心特性

1. **清晰的 9 天 8 晚排期与双城节奏**：
   - **里斯本（前 5 晚）**：住 Hyatt Regency Lisbon，老城经典、百年蛋挞、水陆两栖车与欧洲顶级水族馆。
   - **阿尔加维（后 3 晚）**：机场提 7 座自动挡 MPV 自驾南下，海景套房、Benagil 洞窟游船与佩达德角无障碍木栈道。
2. **🎯 智能天数计算与「自动定位到那一天」**：
   - 手机打开时，根据系统当前日期自动识别处于行程第几天，页面**零延迟平滑滚动聚焦到当天的行程卡片**。
   - 处于行前准备或复盘时，支持通过吸顶胶囊导航一键直达、URL 参数（`?day=N`）或保存上次浏览偏好。
   - 上下滑动浏览时，顶部横向天数胶囊自动感知并高亮当前所在天数（Scrollspy 双向联动）。
3. **🛡️ 全套「省心随身定心丸」**：
   - **带娃点餐神句**：一键全屏放大出示大字卡（*Uma sopa de legumes...* 蔬菜浓汤+白米饭少盐不辣），彻底消除长辈点餐交流焦虑。
   - **餐前小菜 Couvert 避坑提醒**：桌上不碰直接撤走不收费（法律明文保障），0 强制小费。
   - **交通法规定心丸**：葡萄牙交通法第 55 条明确出租车与 Uber 抱幼童后排免安全座椅，合法合规。
   - **超市买奶指南**：认准 Mimosa 200ml 带吸管纯全脂牛奶，避开调味乳。
   - **ATM 防坑**：严禁 Euronet ATM，认准 Multibanco 取款机并选【Continue in EUR (拒绝转换)】。
4. **离线可用与进度记忆**：
   - 每日行程地点支持复选打卡打勾，本地浏览器自动保存进度。
